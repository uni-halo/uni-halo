## 📖 简介

**uni-halo** 是一款基于 [Halo 2.x](https://www.halo.run/) 开放 API 打造的免费开源博客多端应用。一套源码，编译为 **微信小程序（推荐）/ APP / H5**，配合 [Uni Halo 配置插件](https://github.com/uni-halo/uni-halo-plugin) 实现「改内容不改代码」——文章、公告、轮播、恋爱日记等全部内容均可在 Halo 后台动态配置。

## ✨ 特性一览

| | 特性 | 说明 |
|:---:|---|---|
| 📱 | **多端编译** | 基于 uni-app，一套源码编译微信小程序、APP、H5 |
| 🔌 | **插件化配置** | 页面内容、功能开关全部由配套插件管理，无需改源码 |
| 💕 | **恋爱日记** | 相册（密码锁定，页内解锁）/ 清单 / 故事，专为秀恩爱设计 |
| 🔐 | **账号体系** | 账号密码登录、注册、微信一键登录与绑定，按角色控制可见内容 |
| 📲 | **移动端管理** | 管理员可在手机上直接管理恋爱相册、清单、故事与瞬间 |
| 🎨 | **现代技术栈** | Vue3 + TypeScript + Vite + UnoCSS + wot-ui，界面精美、开发体验佳 |
| 🆓 | **完全开源** | 应用与插件源码全部开放，Apache License 2.0 |

## 🧩 功能模块

### 基础功能

文章列表 / 分类 / 标签 / 详情 / 归档 / 搜索 / 公告 / 图库与我的收藏 / 瞬间 / 友情链接（支持投稿申请）/ 投票中心 / 数据看板 / 联系博主 / 偏好设置

### 💕 恋爱日记（特色）

精心设计的秀恩爱模块：情侣甜蜜相册（支持查看密码，页内解锁，服务端保证安全）、恋爱记录清单、我们的故事。配套插件内置恋爱日记前台模板，站点主题装上插件即可直接展示。

![恋爱日记](https://gcore.jsdelivr.net/gh/uni-halo/uni-halo-static/screenshots/app/v3.x/恋爱日记.jpg)

### 🔐 登录与管理

- 账号密码登录、注册、微信小程序一键登录与微信绑定
- 登录后使用 Halo 原生令牌，内置登录限流保护
- 按角色控制菜单与按钮的可见性，管理员与普通用户看到不同的功能
- 管理员移动端直管：恋爱相册 / 恋爱清单 / 恋爱故事 / 瞬间

### 其他

站点维护模式页 / 公告通知 / 应用版本检查更新 / 数据统计可视化

## 🚀 快速开始

### 环境要求

- [Halo](https://www.halo.run/) ≥ 2.26（站点程序）
- Node.js ≥ 20、pnpm ≥ 9
- 发布微信小程序需 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 本地运行

```bash
# 1. 克隆源码
git clone https://github.com/uni-halo/uni-halo.git

# 2. 安装依赖
cd uni-halo
pnpm install

# 3. 启动开发服务（H5 预览）
pnpm dev:h5

# 4. 编译微信小程序（用微信开发者工具导入 dist/dev/mp-weixin）
pnpm dev:mp-weixin
```

> ⚠️ 运行前请先配置站点地址等环境变量，并安装启用 [Uni Halo 配置插件](https://github.com/uni-halo/uni-halo-plugin)。完整的部署、配置与发布流程请阅读 [部署指南](https://uni-halo-doc.ialley.cn/deploy/intro)。

## 🔗 配套插件

[Uni Halo 配置插件](https://github.com/uni-halo/uni-halo-plugin) 是本应用的核心配套插件，提供：

- **内容管理**：横幅轮播、公告、友链（投稿审核 + 邮件通知）、恋爱相册 / 清单 / 故事
- **应用管理**：应用信息维护、版本管理与检查更新
- **恋爱日记前台模板**：任何主题零成本接入恋爱日记页面
- **安全与登录**：验证码防护、移动端登录开关与微信密钥配置
- **主题扩展**：小程序悬浮窗、平台接入（第三方插件）
